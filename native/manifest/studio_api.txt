# haxefmod native FFI manifest - the source of truth for the native surface.
#
# Every function listed here must exist with matching arity in all three shims:
#   native/faxe/linc_faxe.cpp   (C++ / hxcpp)     as fmod_<name>(...)
#   native/hlaxe/hlaxe_fmod.c   (C / HashLink)    as DEFINE_PRIM(<ret>, <name>, <args>)
#   native/jaxe/jaxe.js         (JS / Emscripten) as static fmod_<name>(...)
#
# Verified by: haxelib run haxefmod verify-native
#
# Format: <name> <argtype> <argtype> ... -> <rettype>
# Types are logical (exact FFI types differ per backend, e.g. f32 vs f64);
# the checker verifies presence and arity, not exact types.
#
# abi-version: 7
# The binding ABI version covers the shape of the native surface. Bump it in
# lockstep with the "hlaxe_fmod_abi=" marker in hlaxe_fmod.c, the constants in
# the other two shims, and FmodRuntime.BINDING_ABI whenever functions are
# added, removed, or change signature. PostBuild.hx scans pre-built hdlls for
# the marker and refuses mismatches before they become loader fatals.
#
# Naming domains: sys_, bank_, evd_, evi_, bus_, vca_, cb_, ps_, core_.
# Functions without a domain prefix predate the domain naming and are kept as is.

# Conventions for the domain-prefixed surface:
# - GUIDs cross the boundary as formatted strings "{8-4-4-4-12}" both ways.
# - Parameter IDs cross as two i32 args (data1, data2).
# - fbuf = caller-passed scratch double buffer, ibuf = scratch int buffer
#   (see haxefmod/studio/native/Scratch.hx); layouts documented per function.
# - 3D attributes are 12 flattened doubles: pos xyz, vel xyz, forward xyz, up xyz.
# - List getters fill ibuf with handles and return the count written, capped
#   at FAXE_LIST_MAX (1024, lockstep with Scratch.CAPACITY); lastResult
#   reports errors and the abstracts warn on truncation.
# - Functions missing from the FMOD JS API return FMOD_ERR_UNSUPPORTED (68)
#   on the js backend: sys_get_memory_usage, bus/evi cpu+memory usage.

## Runtime init

# sampleRate 0 = FMOD default; speakerMode 0 = default (FMOD_SPEAKERMODE);
