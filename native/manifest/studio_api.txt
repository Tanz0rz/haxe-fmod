# haxefmod native FFI manifest - the source of truth for the native surface.
#
# Every function listed here must exist with matching arity in all three shims:
#   native/faxe/linc_faxe.cpp   (C++ / hxcpp)     as fmod_<name>(...)
#   native/hlaxe/hlaxe_fmod.c   (C / HashLink)    as DEFINE_PRIM(<ret>, <name>, <args>)
#   native/jaxe/jaxe.js         (JS / Emscripten) as static fmod_<name>(...)
#
# Verified by: haxelib run haxefmod verify-native
#
# Format: <name> <argtype> <argtype> ... -> <rettype>
# Types are logical (exact FFI types differ per backend, e.g. f32 vs f64).
# The checker verifies presence and arity rather than exact types.
#
# abi-version: 10
# The binding ABI version covers the shape of the native surface. Bump it in
# lockstep with the "hlaxe_fmod_abi=" marker in hlaxe_fmod.c, the constants in
# the other two shims, and FmodRuntime.BINDING_ABI whenever functions are
# added, removed, or change signature. PostBuild.hx scans pre-built hdlls for
# the marker and refuses mismatches before they become loader fatals.
#
# Naming domains: sys_, bank_, evd_, evi_, bus_, vca_, cb_, ps_, core_.

# System callbacks ride the queue with handle 0 under the 0x20000000
# namespace: core types as 0x20000000 | type, studio types as 0x20000100 | type.
# BANK_UNLOAD carries the bank path in str (read ahead of bank_unload and
# sys_unload_all, FMOD refuses bank reads inside the callback). Mask 0
# removes the callback.
# Core mask bits: DEVICELISTCHANGED 0x1, DEVICELOST 0x2. Studio mask bits:
# PREUPDATE 0x1, POSTUPDATE 0x2, BANK_UNLOAD 0x4, LIVEUPDATE_CONNECTED 0x8,
# LIVEUPDATE_DISCONNECTED 0x10.

# Conventions for the domain-prefixed surface:
# - GUIDs cross the boundary as formatted strings "{8-4-4-4-12}" both ways.
# - Parameter IDs cross as two i32 args (data1, data2).
# - fbuf = caller-passed scratch double buffer, ibuf = scratch int buffer
#   (see haxefmod/studio/native/Scratch.hx); layouts documented per function.
# - 3D attributes are 12 flattened doubles: pos xyz, vel xyz, forward xyz, up xyz.
# - List getters fill ibuf with handles and return the count written, capped
#   at FAXE_LIST_MAX (1024, lockstep with Scratch.CAPACITY); lastResult
#   reports errors and the abstracts warn on truncation.
# - Functions missing from the FMOD JS API return FMOD_ERR_UNSUPPORTED (68)
#   on the js backend: sys_get_memory_usage, bus/evi cpu+memory usage.

## Runtime init
# Settings-driven init: (numChannels, sampleRate, speakerMode, studioFlags,
# dspBufferLength, dspNumBuffers, softwareChannels, streamBufferSize, initFlags).
# sampleRate 0 = FMOD default; speakerMode 0 = default (FMOD_SPEAKERMODE);
# studioFlags bit0 = live update. dspBufferLength/dspNumBuffers 0 = FMOD
# default (js ignores them, the web build fixes 2048x2). softwareChannels 0 =
# default. streamBufferSize is bytes, 0 = default. initFlags bit0 = profiling
# (FMOD_INIT_PROFILE_ENABLE), bit1 = distance filter
# (FMOD_INIT_CHANNEL_DISTANCEFILTER). Keeps the FMOD_WAVWRITER env branch.
# On js this stores settings and kicks off module init (poll sys_is_initialized).
# Arguments after initFlags are the advanced settings, zero or "" for the
# FMOD default: maxMPEGCodecs, maxVorbisCodecs, maxFADPCMCodecs, vol0VirtualVol,
# defaultDecodeBufferSize, profilePort, geometryMaxFadeTime, distanceFilterCenterFreq,
# randomSeed, then the studio ones: commandQueueSize, handleInitialSize,
# studioUpdatePeriod, idleSampleDataPoolSize, streamingScheduleDelay, encryptionKey.
sys_init_ex i32 i32 i32 i32 i32 i32 i32 i32 i32 i32 i32 i32 f32 i32 i32 i32 f32 i32 i32 i32 i32 i32 i32 str -> i32
# FMOD_Debug_Initialize level (0=none 1=error 2=warning 3=log); file logging
# not exposed. ERR_UNSUPPORTED on js (logging is baked into the wasm build).
sys_set_debug_level i32 -> i32
# Async bank load: native = loadBankFile NONBLOCKING; js = fetch into MEMFS
# then loadBankFile, with the returned handle backed by a placeholder until
# the fetch lands. Poll bank_get_loading_state (js reports LOADING while the
# fetch is pending, ERROR on fetch failure).
sys_load_bank_async str -> i32
